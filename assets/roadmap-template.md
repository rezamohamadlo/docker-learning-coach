## Phase 1 — Container mental models

### Learn

- [ ] Explain image, container, registry, and Docker Engine.
- [ ] Explain the container lifecycle and predict common CLI results.
- [ ] Explain writable layers, bind mounts, and named volumes.

### Build

- [ ] Create a visual map of image → container → process.
- [ ] Run and inspect a disposable container independently.
- [ ] Persist data with a named volume and explain the result.

### Exit criteria

- [ ] Explain the core Docker model without notes.
- [ ] Run, inspect, stop, and remove a container safely.
- [ ] Choose the correct storage approach for a scenario.
