# First learning session

Time: about 20–30 minutes, usually 25.
You do not need any Docker knowledge to start.

## Goal

Understand how the Docker client sends commands to the Docker engine. The client is the tool you use to give commands. The engine does the work, such as running containers.

We will also check which computer you will use for the exercises.

## Steps

1. Choose your learning computer (3 minutes). Check whether you will use this Windows computer with PowerShell or another computer.
2. Learn one idea (6 minutes). Use the [client and engine lesson](../../../references/curriculum/phase-0/environment.md). Draw a simple diagram showing how the client reaches the engine. Explain Docker context: the setting that selects which engine receives your commands. Save a short learning note.
3. Check your setup together (9 minutes). Follow [Lab 00](../../../assets/labs/00-setup/README.md) and the [lab guide](../../../references/labs.md). Check whether Docker is available, which engine is selected, and whether it can run Linux containers. Check the client, engine and Compose versions. Compose is a tool for managing several containers together. Save the actual results. If setup is missing, record what is needed and use the official Docker instructions to plan the next step.
4. Try a question on your own (4 minutes). Explain a new example where the client works but cannot reach the engine. Give your answer before the coach explains it.
5. Summarize and save (3 minutes). Explain the main idea in one sentence. Save the key points, check results, any setup problems and the next step.

## How we check progress

You can explain, without help, why a working client does not mean the engine is available.

We also need actual command output to confirm that your setup works. If installation or startup takes too long, we can finish that check in the next session.

## Next step

Continue with the shell and Docker setup. A shell is the program where you type commands, such as PowerShell.

Phase 0 is complete after your setup works and you pass a short review on your own.
