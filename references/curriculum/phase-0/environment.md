# Client, engine, and context

## Mental model

The CLI sends requests to an engine selected by context. A working CLI alone does not prove that engine is reachable. Docker Desktop runs Linux containers using a Linux environment; a Linux server can run Engine directly.

## Guided practice

Run docker version, docker context show, docker info and docker compose version. Identify the server and whether it is the intended learning machine.

## Independent evidence

Explain what you would check when Client is printed but Server fails.

The coach should vary the assessment after guided practice. Explain your prediction before running a check; preserve actual output when runtime behavior is part of the outcome.

## Summary

The CLI sends requests to an engine selected by context.
