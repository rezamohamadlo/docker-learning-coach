# Shell and installation readiness

## Previous-note recap

Recall: Client, engine, and context. Connect that distinction to today’s observation.

## Mental model

Container commands execute through your host shell. PowerShell and Bash differ in variable syntax, quoting and line continuation; a Linux shell inside a container is a separate environment.

## Guided practice

Read the official installation instructions for your OS. Run Lab 00 after installation; do not change daemon permissions merely to silence an error.

## Independent evidence

Identify which commands run on the host versus inside a Linux container.

The coach should vary the assessment after guided practice. Explain your prediction before running a check; preserve actual output when runtime behavior is part of the outcome.
