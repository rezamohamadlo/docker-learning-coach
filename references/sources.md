# Official Docker references

Checked 2026-09-12 (Gregorian source-check date). Consult the current page for OS/version-specific commands. Examples use Linux images and the Compose plugin, with no legacy top-level `version` field. Image tags in labs are learning defaults and can move; record resolved image identities during exercises.

- [Install Docker](https://docs.docker.com/get-started/get-docker/): choose the learner's actual OS.
- [Published ports](https://docs.docker.com/get-started/docker-concepts/running-containers/publishing-ports/): host/container ports and loopback bindings.
- [Volumes](https://docs.docker.com/engine/storage/volumes/): volume lifetime and mounts.
- [Build practices](https://docs.docker.com/build/building/best-practices/): build context, caching and image choices.
- [Compose overview](https://docs.docker.com/compose/): services and lifecycle.
- [Compose startup order](https://docs.docker.com/compose/how-tos/startup-order/): health-gated dependencies.
- [Compose services reference](https://docs.docker.com/reference/compose-file/services/): configuration semantics.

The lessons and lab exercises are original adaptations for this coaching workflow. They are not a copied Docker manual.
